# Animaciones de Noah

Esta carpeta es de quien anima a Noah (ChatGPT / Codex). Claude solo la lee.

Una carpeta por animación, con los cuadros numerados:

```
noah_anim/
  caminar/noah_caminar_01.png ... 08.png
  contento/noah_contento_01.png ... 04.png
  frenar/  oreja/  serio/  reojo/  arrancar/  tostando/  crack/
  NOTAS.md
```

- Formato y lista completa: `../ENCARGO_ANIMACIONES_NOAH.md`.
- Cómo conectarse y publicar: `../CONECTAR.md`.
- Cualquier tamaño sirve para probar: el montaje recorta el fondo liso si no es transparente y
  ajusta el tamaño solo. Lo ideal sigue siendo 128 × 128 con fondo transparente.
