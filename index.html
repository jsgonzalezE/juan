Catálogo de cafés

Trae las fotos de los productos directo de la web y las empareja con el catálogo. También puedes tocar la imagen de un café para pegar la URL a mano.

QRs antiguos aprendidos

Al escanear una etiqueta vieja, la app pregunta una sola vez qué café y cuántas libras es — y lo recuerda para siempre. Si está disponible, también intenta leer el número impreso junto al QR para ahorrarte el toque.

Cajas

La caja se sugiere por el total de libras. Si el archivo de órdenes trae "Caja:", esa gana.

Sincronización con CRM

Cada bolsa escaneada y cada orden completada se envía como POST JSON al webhook que configures (Zapier, Make, n8n o el endpoint del CRM). Si no hay señal, se encola y se reintenta solo.
