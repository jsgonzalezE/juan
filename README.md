# Plantilla Elementor Pro - Juanito Coffee

Esta plantilla recrea el estilo general de la página de referencia de Northplanner, pero adaptada para Juanito Coffee. Incluye estructura, jerarquía visual y secciones listas para personalizar imágenes y contenidos.

## Cómo usarla

1. En WordPress, abre **Elementor → Herramientas → Importar/Exportar Kit**.
2. Selecciona **Importar** y carga el archivo `plantilla-elementor-pro.json`.
3. Asigna la plantilla a una página nueva y reemplaza imágenes, menú y textos.

## Qué debes personalizar

- Logos e imágenes de hero y sección "Nuestra historia".
- Menú de navegación y enlaces de botones.
- Dirección real y detalles de contacto.

## Secciones incluidas

- Hero con navegación, llamados a la acción y espacio para imagen principal.
- Sección de historia con lista de valores.
- Carta destacada con tres productos.
- Sección "Visítanos" con mapa y datos de ubicación.
- CTA final con contacto.
