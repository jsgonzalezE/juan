# Juanito Coffee - Plantilla Elementor Pro

Plantilla de landing page inspirada en la estructura de Northplanner, adaptada para Juanito Coffee y lista para importar en Elementor Pro.

## Cómo usarla

1. Abre tu panel de WordPress y ve a **Elementor → Herramientas → Importar/Exportar Kit**.
2. Elige **Importar** y selecciona el archivo `plantilla-elementor-pro.json`.
3. Sustituye las imágenes de ejemplo (placeholders) por fotos reales del café y ajusta textos, precios y botones.

## Contenido incluido

- Hero con logo, titular, subtítulo y dos botones CTA.
- Sección de historia de marca.
- Sección de especialidades con tres tarjetas.
- Menú destacado con precios.
- Galería con tres imágenes.
- Sección de ubicación y horarios.

## Recomendaciones

- Usa tipografía **Playfair Display** para titulares y una sans-serif para los textos.
- Mantén la paleta en tonos crema, café y arena para conservar el estilo.
